## Color Treatment

### Figma (Primary)
- **Background:** Gradient from surface to accent tint
- **Border:** 2px solid accent (#6C63FF)
- **Icon BG:** Gradient accent soft
- **Hover Glow:** rgba(108, 99, 255, 0.2)

### Canva (Supporting)
- **Background:** Standard surface
- **Border:** 1px solid border
- **Icon BG:** rgba(163, 163, 160, 0.1)
- **No Glow**

### Design Cards
- **Background:** Surface with glass
- **Border:** 1px solid border
- **Hover:** Border-hover color

### Technical
- **Background:** Surface
- **Border:** 1px solid border
- **Text:** Secondary/muted

### Core Tags
- **Background:** Surface
- **Border:** 1px solid border
- **Text:** Secondary

## Accessibility

### Keyboard Navigation
- All cards: `Tab` to focus
- All cards: `2px accent outline` on focus
- All cards: `2px offset` for visibility

### Screen Readers
- Progress bars: `role="progressbar"`
- Progress bars: `aria-valuenow`, `aria-valuemin`, `aria-valuemax`
- Progress bars: `aria-label` with skill name

### Motion
- Respects `prefers-reduced-motion: reduce`
- Disables all transitions
- Proficiency fills still show final state
- No transform animations when reduced motion

---

**Visual Philosophy:**
- Hierarchy communicates importance
- Size reflects significance
- Color emphasizes primary tool
- Restraint maintains credibility
- Honesty over impression
