## 🎨 Design Tool Positioning

### Figma
- **Label:** PRIMARY DESIGN TOOL
- **Level:** CORE (90%)
- **Size:** ~400px height
- **Border:** 2px accent
- **Background:** Gradient with accent tint
- **Icon:** 64px
- **Hover:** Large lift + glow effect
- **Capabilities:**
  - Wireframing
  - Prototyping
  - High-Fidelity UI
  - Design System
  - Visual Design

- **Label:** SUPPORTING TOOL
- **Level:** WORKING (75%)
- **Size:** ~180px height (45% of Figma)
- **Border:** 1px standard
- **Background:** Standard surface
- **Icon:** 48px
- **Hover:** Small lift only

## 💡 Key Design Decisions

### 1. **Honesty Over Impression**
- Only show tools actually used regularly
- Remove Adobe suite without current expertise
- Accurate self-assessment levels

### 2. **Visual Hierarchy = Actual Hierarchy**
- Figma's visual dominance reflects actual usage
- Canva's smaller size reflects supporting role
- Technical skills muted to show support function

### 3. **Credibility Through Restraint**
- No false "expert" claims
- Technical skills show understanding, not mastery
- Process reflects actual UX workflow

### 4. **Designer, Not Developer**
- Technical section clearly labeled as "supporting"
- Design capabilities receive primary treatment
- Figma as centerpiece reinforces designer identity
