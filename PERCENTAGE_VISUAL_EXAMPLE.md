## Layout System

### Flexbox Structure
```html
<div class="skill-proficiency-wrapper">
  <div class="skill-proficiency-bar">     <!-- flex: 1 -->
    <div class="skill-proficiency-fill">  <!-- animated -->
  </div>
  <span class="percentage">90%</span>     <!-- min-width: 38px -->
</div>
```

### CSS
```css
.skill-proficiency-wrapper {
  display: flex;
  align-items: center;
  gap: 0.5rem;              /* 8px spacing */
}

.skill-proficiency-bar {
  flex: 1;                  /* Takes remaining space */
  height: 4px;
}

.skill-proficiency-percentage {
  min-width: 38px;          /* Prevents jumping */
  text-align: right;        /* Right-aligned */
  flex-shrink: 0;           /* Never shrinks */
}
```

## Accessibility Considerations

### Screen Readers
```html
<div role="progressbar" 
     aria-valuenow="90" 
     aria-valuemin="0" 
     aria-valuemax="100"
     aria-label="UI/UX Design proficiency">
  <!-- Visual bar -->
</div>
<span>90%</span>  <!-- Also announced -->
```

### Contrast Ratio
- **Percentage (#6C63FF) on Dark BG (#111111)**: 4.8:1 ✅
- **Percentage (#6C63FF) on Light BG (#FFFFFF)**: 4.5:1 ✅
- **Meets WCAG AA** for normal text

### Keyboard Navigation
- Focusable parent card
- Percentage visible without hover
- No interactive percentage (static display)


### Different Percentage Lengths
```
90%  ← 3 characters
75%  ← 3 characters
100% ← 4 characters (future-proof)

min-width: 38px handles all cases
```

### Narrow Containers
```
Min container width: 280px
Bar minimum: ~180px
Percentage: 38px
Gap: 8px
Padding: 24px (12px × 2)

Total: 250px content + 30px padding = 280px
```

## Performance Considerations

### Animation Optimization
- Uses `transform` (GPU accelerated) ✅
- Bar width animation: CPU (acceptable for once-per-pageload) ✅
- No layout thrashing ✅
- Respects `prefers-reduced-motion` ✅

### Rendering
- Percentage is simple text node (fast) ✅
- No image assets (pure CSS + text) ✅
- Flexbox well-supported (efficient layout) ✅
